GET TO KNOW ME

About Me

A practical engineering mindset, applied to intelligent systems.

Building AI that solves real problems.

I'm an AI/ML engineer with 2+ years of experience building and deploying production-grade computer vision systems. At DigiTele Networks, I built GPU-accelerated drone inspection pipelines using PyTorch, YOLO, Faster R-CNN, and SAM, reaching around 80% mAP on wind turbine inspection. I also developed multispectral drone surveillance models using RGB and thermal imagery for day and night intrusion detection, with about 75-80% mAP. I used Ray for distributed inference, served models through Flask APIs and Docker, and optimized YOLOv5 for edge hardware with ONNX and INT8 quantization, cutting model size by about 75%.

On the GenAI side, I built DocSense, a hybrid-retrieval RAG chatbot deployed on Azure Container Apps with Azure OpenAI, a loan assessment system that pairs XGBoost and SHAP explanations with a policy-grounded RAG pipeline. I also built Jarvis, a voice assistant on a Raspberry Pi that uses LangGraph to call tools like web search and GPIO device control. My earlier background in embedded systems and hardware testing is why I care about systems that run reliably in production, not just in a notebook.
